# Idea rubric

The social team scores each idea in section D. The hard checks are pass/fail; the scored criteria use a 1–3 scale.

## Hard checks (any fail = idea fails)
- [ ] Passed the claims gate (`pass` or `rewritten`)
- [ ] Has all 8 fields (concept, format, hook, shot list / slide outline, caption, CTA, hashtags, source inspiration)
- [ ] Source inspiration is a real URL / trend from this run, or labelled `brand-led, no source`
- [ ] In category (e.g. no cat content for a dogs-only brand)

## Set-level checks (per 10 ideas)
- [ ] Meets the brand profile's idea mix, or names the shortfall
- [ ] CTAs mostly use the main conversion path

## Scored (1 = no, 2 = partly, 3 = yes)
| Criterion | 3 looks like |
|---|---|
| On-brand | Sounds like the brand profile's voice; uses its differentiators |
| Shootable this week | A small team with a phone can film it in a day, in the brand's city, with what it already has |
| Original | Adapts a mechanic; no caption, script or distinctive visual reused |
| Specific | Hook line and shot list are concrete enough to film without a follow-up question |
| Would we post it? | The team would actually post it |

Track over time: average score, % of ideas the team actually shoots.
