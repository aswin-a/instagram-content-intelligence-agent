# Post record schema

One row per competitor post. CSV headers are in [post-record.template.csv](post-record.template.csv).

| Field | Values / notes |
|---|---|
| Account | handle |
| Tier | 1–4 from competitor-list |
| Followers | at time of capture |
| Date | post date |
| Format | Reel / carousel / static / Story |
| Hook | first 3 seconds (Reel) or first line (caption/slide 1) |
| Segment | e.g. puppy / adult / senior / large breed / small breed / active / general |
| Theme | one of: recipe/ingredient reveal, kibble vs fresh, behind-the-kitchen, unboxing/delivery, customer review, vet/nutrition education, taste-test reaction, puppy care tips, breed-specific tips, festival/seasonal, meme/relatable, offer/free sample |
| Visual style | e.g. talking head, POV, overhead kitchen, UGC, motion text |
| Language | e.g. English / Tamil / Tanglish |
| Caption length & CTA | short/medium/long + CTA type: WhatsApp, link in bio, free sample, DM, none |
| Hashtags | as posted |
| Audio | original / trending (name if visible) / none |
| Likes | number or `not available` (hidden) |
| Comments | number or `not available` |
| Views | number or `not available` |
| Engagement rate | (likes + comments) ÷ followers, or `not available` |
| Views ÷ followers | Reels only |
| × account median | this post's metric ÷ account's median for the same format |
| Buying-intent comments | count + examples (paraphrased) |
| Claims flagged | anything passed to claims-check |
| Why it likely worked | **[inference]**, tied to observable features |

Theme and segment lists come from the example brand; change them to fit your category.
