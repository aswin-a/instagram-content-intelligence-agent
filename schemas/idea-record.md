# Idea record schema

One row per content idea in report section D. This makes the mix rule and the claims gate checkable, and gives each idea an ID so its performance can be tracked once it's posted (see the roadmap). CSV headers: [idea-record.template.csv](idea-record.template.csv).

| Field | Values / notes |
|---|---|
| Idea ID | `<run date>-<n>`, e.g. `2026-01-15-03` |
| Concept | one line |
| Format | Reel / carousel / static / Story |
| Hook line | first 3 seconds or first line |
| Shot list or slide outline | numbered beats |
| Caption draft | brand voice |
| CTA | from the brand profile's conversion path |
| Hashtags | category + local + branded |
| Mix tags | any of: `life-stage`, `education-trust`, `customer-proof`, `breed-specific` (from the brand profile's idea mix) |
| Source inspiration | post URL or trend it adapts + what changed; or `brand-led, no source` |
| Claims check | `pass` / `rewritten: <what changed>` (ideas that fail are dropped, not listed) |
