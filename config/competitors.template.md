# Competitor list (template)

Add this to the Claude Project as a doc named **competitor-list**. Tiers set how each account is compared, so a huge brand doesn't skew what "good" looks like.

| Tier | Meaning | How it's used |
|---|---|---|
| 1. Local peers | Same category, same city/region | Direct benchmark: patterns, gaps, CTAs |
| 2. National peers | Same category, other regions | Patterns and formats |
| 3. Reach context | Big adjacent brands, not category peers | Format and hook ideas only; never a metric benchmark |
| 4. Global benchmarks | Best-in-class category brands abroad | Craft and storytelling ideas; local fit checked |
